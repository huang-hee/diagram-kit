# 配色与版式规则

出图要好看，主要靠五件事：颜色有语义且克制、形状和尺寸统一、对齐到网格、连线干净、留白足够。

## 颜色

- 颜色表达"类型 / 角色"，同一角色全图同色；分组用容器（subgraph / 泳道 / 边界）表达，不靠换颜色。
- 结构类的图，填充色不超过 4 种角色色 + 1 个强调色；状态色另算，按系列色轮换的图型（饼图、思维导图、时间线、看板、Git 图）不受此限。
- 强调色（主色）只给关键路径、本次改动、中心主题、核心实体这类"只有一处"的东西。
- 状态色只表示状态：成功、警告、失败 / 异常、信息、已完成，不拿来区分类型。
- 容器底色用 soft（描边色的浅调），边界用虚线，外部系统用灰色。
- 连线用方案的 `line` 色，描边由 palette 派生，都不手调。
- 文字颜色以 palette.py 的输出为准，已经过 WCAG 对比度检查（正文 4.5:1，实色块上的短标签 3:1）。自己改了填充色，要用 `palette.py check` 或对比度工具重新确认。
- 同一篇文档、同一批图只用一套方案。
- 不用渐变、阴影、3D 效果。

## 形状与尺寸

- 以圆角矩形为主；同一类节点同一尺寸。
- 形状有语义（起止胶囊、处理矩形、判断菱形、数据库圆柱……），各图的写法见对应参考文件。
- drawio 常用尺寸：处理 120×48、判断 120×64、起止 120×40、图标 48×48；容器内边距 20。
- 描边 1px，强调 2px；连线 1px。

## 对齐与间距（drawio）

- 打开 10px 网格，节点中心对齐。
- 同层节点等间距：横向 40–60px，纵向不小于 40px；容器之间不小于 30px。
- 主路径在一条直线上，分支向同一侧展开。
- 画布四周留白，不要把图塞满。
- Mermaid 是自动布局，这几条只能靠调节点顺序、方向和不可见连线来逼近。

## 连线

- 流程、架构用正交折线，脑图用曲线。
- 箭头统一用实心小三角。
- 同步调用、主流程用实线；异步、返回、依赖用虚线。
- 避免交叉：调换节点顺序、换方向、或者拆图；实在要交叉时用跳线（drawio `jumpStyle=arc`）。
- 线上标签不超过 6 个字；判断的每个出口都要有标签（是 / 否）。

## 文字与层级

- drawio 字号：标题 18、容器标题 14 加粗、节点 13、线标签 11、说明 12。
- 节点文字不超过 12 个汉字，长了就换行或精简。
- 流程步骤用"动词 + 宾语"，结构节点用名词；不加句号。
- 中文与英文、数字之间加空格。

## 规模与方向

- 单图节点上限 12 个；超过就拆成"总览 + 子图"，或改用 drawio。
- 嵌套不超过 3 层。
- 流程：一张图只用 TB 或 LR 一种方向；时间从左到右；分层自上而下（用户 → 接入 → 服务 → 中间件 → 数据 → 基础设施）。

## 图例

- 用了 3 种以上语义色时加图例：Mermaid 在图下面用一行文字或小表格说明（用 subgraph 拼图例会打乱布局），drawio 放在右下角。

## 出图检查清单

- [ ] 图型选对了（对照该图的"别用"）
- [ ] 节点数没超上限，没有孤立节点
- [ ] 颜色按角色上，同角色同色；强调色只用在一处
- [ ] 文字没有截断、溢出；中文字体正常
- [ ] 连线没有交叉（或已处理）；判断出口都有标签
- [ ] 方向一致，同层对齐
- [ ] 渲染通过（Mermaid 渲染 MCP / mmdc / drawio 导出）
- [ ] 图片和可编辑源文件按调用者或项目的规则存放
