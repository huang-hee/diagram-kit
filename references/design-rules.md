# 配色与版式规则

出图要好看，主要靠六件事：颜色有语义且克制、形状和尺寸统一、对齐到网格、连线等粗正交且干净、信息分层（标题 / 主体 / 说明）、留白足够。

这套规则对 drawio、Mermaid、diagram-design 三种工具统一适用；每个工具怎么落地见 tools.md 对应一节。drawio 精修出图用 `scripts/drawio_kit.py`，样式令牌已按本文件写好。

## 版式骨架

- 一张图分三块，自上而下：标题区 → 主体 → 说明区。
- 标题区：左侧 6px 主色竖条，右边是标题和副标题。标题 22 加粗，不带图号（图号写在文档的小标题里）。副标题 13、次要字色，用一句话写这张图回答的问题。
- 主体：分层带、分组容器、节点、连线。
- 说明区：说明面板（依据、例外、「不在这张图里」）→ 图例 → 一行「读图：……」。没有需要说明的就省掉。
- Mermaid 只有标题位（frontmatter `title`），副标题、说明和图例写在图下面的文档正文。diagram-design 用它自己的标题位和 eyebrow 放副标题。
- 画布四周留白不少于 40；区块之间不少于 30。

## 颜色

- 颜色表达"类型 / 角色"，同一角色全图同色；分组用容器（分层带 / 泳道 / 边界）表达，不靠换颜色。
- 结构类的图，填充色不超过 4 种角色色 + 1 个强调色；状态色另算，按系列色轮换的图型（饼图、思维导图、时间线、看板、Git 图）不受此限。
- 强调色（主色实底白字）一张图只给 1–2 个焦点：关键路径、本次改动、中心主题、核心实体、跨泳道交接点。
- 状态色只表示状态：成功、警告、失败 / 异常、信息、已完成，不拿来区分类型。
- 待定、未确认、示意的元素：灰底、灰色虚线描边、次要字色，文字里标「待定」。
- 系列色分三级深浅，层级一眼可辨：一级用系列色的深色实底配白字，二级用系列浅色底、不描边，三级用白底配系列色细描边。
- 容器底色用 soft（描边色的浅调），边界用虚线，外部系统用灰色。
- 连线用方案的 `line` 色，描边由 palette 派生，都不手调。
- 文字颜色以 palette.py 的输出为准，已经过 WCAG 对比度检查（正文 4.5:1，实色块上的短标签 3:1）。自己改了填充色，要用 `palette.py check` 或对比度工具重新确认。
- 同一篇文档、同一批图只用一套方案。
- 不用渐变、阴影、3D 效果。

## 节点

- 以圆角矩形为主，圆角半径固定 8px（drawio 用 `absoluteArcSize=1;arcSize=8`，不随尺寸变化）。
- 形状有语义：起止用胶囊，处理用矩形，判断用菱形，数据库用圆柱，数据或文档用平行四边形，……各图的写法见对应参考文件。
- 两级文字：第一行主名，13 号加粗；第二行起是说明，11 号常规，用同色系的字色。主名用名词或「动词 + 宾语」，说明写职责、字段或取值。
- 同一类节点同一尺寸，宽度按这一类里最长的文字统一。参考尺寸如下：

  | 节点         | 尺寸            |
  | ------------ | --------------- |
  | 单行处理     | 120×48          |
  | 带说明的卡片 | 200–260 × 64–72 |
  | 判断菱形     | 200×88          |
  | 起止胶囊     | 160×44          |
  | 图标         | 48×48           |

- 描边 1px；强调和一级分支 1.5–2px。容器内边距 20。

## 分层与分组

- 层、泳道、运行位置、阶段用横向分层带：左侧是 120–150 宽的标签栏（ramp 最浅色底，标签 14 加粗，可加 11 号小字副标签），右侧是 soft 浅底的内容区。两者都不描边、圆角 8，层与层之间留 16–20 的间隙。
- 横切关注点（原则、治理、安全）用右侧的纵向贯穿条，跨越它覆盖的那几层。
- 一组相关节点用分组容器：soft 浅底、无边框、左上角写组名；只表示边界时用虚线框、不填充。
- 嵌套不超过 3 层。

## 对齐与间距

- 打开 10px 网格，坐标和尺寸取 10 的倍数，节点中心对齐。
- 同层节点等间距：横向 40–60，纵向不小于 40；带标签的连线两端至少隔 60，标签不压节点。
- 主路径在一条直线上，分支统一向一侧展开，分支的结果列左对齐。
- Mermaid 是自动布局，这几条只能靠节点顺序、方向、`nodeSpacing` / `rankSpacing` 和不可见连线来逼近。

## 连线

- 一律用正交折线，转角带小圆角。不用曲线和斜线；鱼骨图的骨线是唯一例外。脑图的分支线也用正交肘线，从父节点侧边中点出、到子节点侧边中点进。
- 线宽全图统一 1.5px；关键路径 2.5px。全图只用一个线色（方案的 line 色），只有脑图和树的分支线跟随分支的颜色。
- 箭头统一用实心小三角，大小一致；脑图和树的连线不带箭头。
- 实线表示主流程、同步调用、运行时调用；虚线（6 4）表示异步、返回、依赖、注册、只依赖类型。
- 端口：线从节点某条边的中点出入。同一个节点的多条线分到不同的边，或同一边的 1/4、3/4 处。优先画成直线或只折一次的 L 形；回环、跨层的线用显式拐点绕到外侧通道走。
- 不许两条线共用一段，不许穿过节点；交叉靠调换节点顺序消除，实在消不掉才用跳线（drawio `jumpStyle=arc`）。
- 线上标签不超过 6–8 个字，白底，放在线段中部；判断的每个出口都要有标签（是 / 否）。

## 文字与层级

- 字号：

  | 用途         | 字号                   |
  | ------------ | ---------------------- |
  | 标题         | 22 加粗                |
  | 副标题       | 13                     |
  | 分层标签     | 14 加粗                |
  | 节点主名     | 13 加粗                |
  | 节点说明     | 11                     |
  | 线标签       | 12                     |
  | 说明面板     | 12（面板标题 13 加粗） |
  | 图例、读图行 | 12 次要字色            |

- 字体链：`PingFang SC, Microsoft YaHei, Noto Sans CJK SC, Source Han Sans SC, sans-serif`。
- 节点主名不超过 12 个汉字，长了就换行或精简；长句不塞进节点，放进说明面板。
- 流程步骤用"动词 + 宾语"，结构节点用名词；不加句号。
- 中文与英文、数字之间加空格。

## 说明面板与图例

- 说明面板：note 色（浅黄底、浅棕描边）放依据、规则编号、例外；soft 色放次要信息（「不在这张图里」「查询时才计算」）。面板高度按文字量定，不留大片空白。
- 图例：用了 3 种以上语义色，或者有实线 / 虚线两种连线时加图例，放在主体下方，一行左对齐。每项是一个色块或一段线样，配 12 号文字。
- 读图行：图例下面一行「读图：……」，说清楚方向、颜色和线型怎么读；只写图里能看到的东西，不写引申的结论。

## 规模与方向

- Mermaid：有连线的图（流程、架构、部署、网络、类、ER、状态、用例）单图节点上限 12 个，超过就拆成"总览 + 子图"，拆不开改用 drawio。
- drawio：不受节点数限制，但要按分层带或分组组织；一张图只回答一个问题。
- 脑图、树形 / 组织结构、时间线、甘特、看板、饼图按层级或序列排，不受节点上限限制，只受各自的要点约束（如脑图一级分支 ≤ 6、嵌套 ≤ 3 层）。
- 流程：一张图只用 TB 或 LR 一种方向；时间从左到右；分层自上而下（用户 → 接入 → 服务 → 中间件 → 数据 → 基础设施）。

## 各图型的版式做法

| 图型                                       | 做法                                                                                                                                                          |
| ------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 思维导图                                   | 中心主题用主色胶囊；一级分支按系列色轮换、深色实底白字，左右两侧均分；二级用浅底，三级用白底细描边；同一级同宽，叶子竖向等距；连线用分支色的正交肘线。        |
| 树形 / 组织结构                            | 自上而下或自左而右；根用强调色，一级按系列色轮换；同层节点同高，子树在父节点下居中；用总线式肘线。                                                            |
| 流程图 / 决策树                            | 主路径竖排成一列，起止用胶囊，判断用菱形；每道判断的另一出口统一向右，落到对齐的结果列；结果按语义上色，最终结论用强调色；右侧放依据面板。                    |
| 泳道图                                     | 每条泳道是一条横向分层带，左侧标签栏写角色或模块；步骤沿时间从左到右排列，列宽相等；跨泳道的线是单折 L 形，交接点用强调色；返工、回退路径用虚线，走外侧通道。 |
| 分层架构（业务、应用、技术）               | 每层一条横向分层带，层内卡片网格对齐、等宽；横切关注点用右侧贯穿条；外部系统用灰色，放最上层或最外侧。                                                        |
| 时序图                                     | 参与者头卡片等距排一行，下面是虚线生命线；消息是水平实线加实心箭头，返回用虚线，竖向等距；alt / opt 片段用虚线框，左上角写标签；注释用 note 色小卡片。        |
| 状态图                                     | 起点是实心圆，终点是外环加实心圆；状态用圆角卡片；转移线写触发条件；终态按状态色上色。                                                                        |
| ER / 类图                                  | 每个实体是一张表格卡片：表头用角色色，下面一行一个字段，主键加粗、外键用次要字色、分组之间加分隔线。关系线从表的侧边出入，标注基数或关系词。                  |
| 鱼骨图                                     | 鱼头（问题）在右侧，用杏色卡片；主骨是粗水平线；大类卡片上下交替排列，斜骨连到主骨；原因是短横线加右对齐的文字。                                              |
| 时间线 / 路线图                            | 一条水平主轴，分段着色；节点是圆点或圆形图标；文字上下交替，避免拥挤。                                                                                        |
| 甘特图                                     | 左侧是任务列，顶部是日期刻度；条形按系列色区分阶段，里程碑用菱形。                                                                                            |
| 看板                                       | 列等宽，列头用系列色；卡片白底细描边，宽度统一。                                                                                                              |
| 用户旅程                                   | 顶部是阶段箭头条；下面每行一个维度（行为、触点、想法、痛点）；情绪曲线由分值点连成折线，配表情或分值。                                                        |
| 象限图                                     | 四个象限用四种浅底；元素是编号圆点加短标签；坐标轴写清两端的含义；右侧面板列出编号对照和评分口径。定性摆位要注明。                                            |
| 数据图（柱、饼、散点、雷达、桑基、矩形树） | 坐标轴、刻度、数值标签齐全，用系列色；超过 3 个系列用小多图；数字取自数据文件，图下注明来源。                                                                 |

## 出图检查清单

- [ ] 图型选对了（对照该图的"别用"）
- [ ] 有标题区，副标题说清这张图回答的问题；标题不带图号
- [ ] 节点数没超上限（Mermaid），没有孤立节点
- [ ] 颜色按角色上，同角色同色；强调色不超过 2 处；待定项是灰色虚线
- [ ] 同类节点同尺寸、对齐到网格；分层带与分组清楚
- [ ] 连线等粗、正交，没有共用线段、没有穿框、没有交叉（或已处理）；判断出口都有标签，标签不压框
- [ ] 文字没有截断、溢出；中文字体正常
- [ ] 需要的说明面板、图例、读图行都在，面板没有大片空白
- [ ] 渲染通过（Mermaid 渲染 MCP / mmdc / drawio 导出），并看过导出的图片
- [ ] 图片和可编辑源文件按调用者或项目的规则存放
